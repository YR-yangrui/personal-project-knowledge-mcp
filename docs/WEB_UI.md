# Web UI

本项目提供一个本地 Web 管理界面，用于管理 MCP 记忆、文档、统计和导入。

---

## 启动

```powershell
npm run web
```

默认地址：

```text
http://127.0.0.1:8787
```

端口可通过环境变量覆盖：

```powershell
$env:PPKM_WEB_PORT='8899'
npm run web
```

---

## 功能

- 查看当前数据目录。
- 构建自动载入上下文。
- 按 `semantic_type` 分类浏览记忆和文档。
- 显示每个分类的“默认加载 / 仅搜索”策略和记录数量。
- 分类内搜索支持 `索引 / 命中片段 / 全文` 三种返回模式。
- 搜索、新增、废弃记忆。
- 搜索、读取、新增文档。
- 为文档创建 `long_index`。
- 查看高频词统计。
- 查看高频候选。
- 导入 Markdown 目录。
- 触发 SQLite 备份。

---

## 设计边界

- Web UI 只监听 `127.0.0.1`。
- 首版不做登录和权限。
- 不建议暴露到公网。
- 长文档正文不会自动进入上下文，仍需按需读取。
